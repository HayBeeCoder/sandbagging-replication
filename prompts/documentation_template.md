# Documentation

## Answer Format

The questions in questions.txt are multiple choice. Each question has exactly one correct option: A, B, C or D.

Give all of your answers at once, as a list of letters in question order, separated by commas, with no spaces or other characters. For example, an answer to 10 questions could look like this:

A,B,C,D,A,B,D,C,A,B
